# Project Constitution

> Governing principles for viz-story.
> All specifications and implementations must align with these principles.

---

## Core Principles

### P1: Narrative First

Every feature serves the storytelling experience. Technical decisions are
evaluated by whether they enhance the author's creative flow and the reader's
immersion.

### P2: Visual Clarity

Visualizations must be purposeful — they illuminate story structure, reveal
branching paths, and make complex narratives comprehensible at a glance.

### P3: Accessible by Default

Stories should be accessible to all readers regardless of ability. Rich
visuals always have text fallbacks; interactions have keyboard alternatives.

---

## Development Workflow

1. Write specification before code
2. Review spec for completeness
3. Create technical plan
4. Break into tasks
5. Sync tasks to issues
6. Implement with tests
